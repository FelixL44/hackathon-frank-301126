# Photos wanted

Messages and estimate PDFs here are generated by `npm run fixtures:generate`. Photos must be added by hand.

Rules: synthetic or your own car, **no readable real number plate, no people, no location clues**. JPEG, under 2 MB.

| File | Shows |
| --- | --- |
| `F1/photo-1.jpg` | Scratches on the **front** bumper, clearly from the front |
| `F2/photo-1.jpg` | Same damage, **blurry** or from an angle where front/rear cannot be told |
| `F3/photo-1.jpg` | Scratches on the **front** bumper (the estimate in F3 wrongly says rear) |

Until a photo exists, a model-backed run reports `missing_object` for it and routes the case to broker review.
